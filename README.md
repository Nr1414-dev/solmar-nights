SOLMAR NIGHTS is an open-world crime game that runs in a desktop browser: drive and steal cars across the sun-soaked coastal city of Solmar, outrun the police through a 5-star wanted system, run six story missions for fixer Mara Solis, take taxi fares, find 12 hidden packages, and buy your way out of trouble at the gun store, the spray shop and the diner. 2D top-down, keyboard + mouse, vanilla JavaScript with no libraries and no network — the whole city, traffic, pedestrians, police AI, day/night cycle and soundtrack are generated in code.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in a desktop browser
```
